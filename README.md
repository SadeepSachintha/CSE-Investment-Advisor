# Colombo Stock Exchange (CSE) Investment Advisor App

An interactive investment advisor and virtual trading portfolio simulator for the Colombo Stock Exchange (CSE).

## 🚀 Hugging Face Deployment

This Space is configured to run using the **Static SDK**, serving the static HTML5, CSS3, and ES6+ JavaScript files directly.

### Features
*   **Live Market Pulse**: ASPI and S&P SL20 tickers, daily gainers/losers/active indexes, and live trading timers.
*   **Stock Explorer**: Comprehensive GICS sector filtration, keyword searches, and multi-metric sorting.
*   **Portfolio Sandbox**: Start with LKR 1,000,000.00 virtual capital, execute mock trades, and inspect sector risk weights.
*   **Ariya AI Advisor**: Chat interface for automated portfolio risk models, macro bulletins, and dividend screens.
*   **Statutory Fee Calculator**: Models exact CSE entry/exit commissions to analyze break-even margins.

### Local Installation
If you prefer running this locally under a web server like XAMPP:
1. Clone this repository into your `htdocs` directory.
2. Open `http://localhost/CSE-Investment-Advisor` in your browser.
